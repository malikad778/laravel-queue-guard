# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `laravel-queue-guard`, please send an email to the maintainers. All security vulnerabilities will be promptly addressed.

Please do not report security vulnerabilities via public GitHub issues.
